# 1131603 Android Project

## 專案簡介

本專案使用 Android Studio 開發，作為 Android 應用程式設計課程的期末專案。

## 使用技術

- Kotlin
- Android Studio
- XML Layout
- Gradle

## 專案功能

- Android App 介面設計
- Fragment 頁面切換
- 以 Kotlin 撰寫應用程式邏輯
- 使用 XML 設計 UI 版面與資源

## 專案結構

- `app/src/main/java/`：Kotlin 程式碼
- `app/src/main/res/`：圖片、版面與其他 Android 資源
- `gradle/`：Gradle Wrapper 與版本設定

## 開發工具

Android Studio

## 備註

本專案為學習與作品集展示用途。
